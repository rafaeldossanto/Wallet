# Fixtures da Pluggy

Respostas **sintéticas**, montadas a partir dos tipos do SDK oficial
(`github.com/pluggyai/pluggy-node`, `src/types`). Nenhum dado real.

Quando o spike T02 rodar com o Meu Pluggy, substituir por respostas reais **anonimizadas**
(nomes, CPF, números de conta, descrições e valores trocados, mantendo formato e sinal).
